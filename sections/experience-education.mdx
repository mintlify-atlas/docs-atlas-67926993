---
title: "Work experience and education in the portfolio"
description: "Experience and Education use CommonItem and the Card component. Add entries to Experience.json or Education.json — the data format is identical for both."
---

The Experience and Education sections share the same `CommonItem` TypeScript interface, the same `Card` component, and the same `useSectionData` hook pattern. The only difference between them is which JSON file they load: `Experience.json` or `Education.json`. This means adding or editing entries works identically for both sections.

## CommonItem type

Both sections use the `CommonItem` interface defined in `src/app/types/Section.ts`:

```typescript src/app/types/Section.ts
export interface CommonItem {
  title: string;
  subtitle: string;
  duration: string;
  detail: React.ReactNode;
  className?: string;
  link?: string;       // Optional URL rendered as a button or link
  linkIcon?: IconType; // Optional icon component for the link
}
```

The `link` and `linkIcon` fields are optional. When `link` is present, the `Card` component renders it as a clickable element.

## Adding an experience or education entry

<Steps>
  <Step title="Open the correct JSON file">
    Open `src/app/data/Experience.json` to add a work entry, or `src/app/data/Education.json` to add an academic qualification.
  </Step>
  <Step title="Add a new object to the array">
    Append a new object with `title`, `subtitle`, `duration`, and `detail`. Add `link` only if you want a button linking to a certificate, company page, or other URL.

    ```json
    {
      "title": "Senior Software Engineer",
      "subtitle": "Acme Corp",
      "duration": "Jun 2025 - Present",
      "detail": "Description of your responsibilities, achievements, and technologies used in this role.",
      "link": "https://acmecorp.example.com"
    }
    ```
  </Step>
  <Step title="Save the file">
    Save the JSON file. The new `Card` appears automatically in the corresponding section on next page load.
  </Step>
</Steps>
