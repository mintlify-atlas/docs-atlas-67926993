The Projects section reads its data from `src/app/data/Project.json` via the `useSectionData` hook and renders one `ProjectCard` per entry. Each card shows a project image, a short description, a list of highlight bullet points, tech stack badges, and a link to the live deployment. Cards animate in with a staggered fade-up as they scroll into view, and the grid switches from one column on small screens to two columns on extra-large screens.

## ProjectItem type

The shape of each project entry is defined by the `ProjectItem` interface in `src/app/types/Section.ts`:

```typescript src/app/types/Section.ts
export interface ProjectItem {
  title: string;
  image: string;
  detail: string;
  points: string[];
  className?: string;
  link: string;
  techStack: string[];
  linkIcon?: IconType;
}
```

<Note>
  The JSON field is `"details"` (plural) but the TypeScript interface declares `detail` (singular). The Web Worker that loads the data maps the JSON onto this interface. When adding a new project, use `"details"` as the JSON key to match the existing entries.
</Note>

## Adding a project

<Steps>
  <Step title="Open Project.json">
    Open `src/app/data/Project.json` in your editor.
  </Step>
  <Step title="Add a new project object">
    Append a new object to the array following the `ProjectItem` shape. Fill in all required fields: `title`, `image`, `details`, `points`, `link`, and `techStack`.

    ```json
    {
      "title": "My New Project",
      "image": "/assets/my-new-project.jpg",
      "details": "A short description of what the project does and the problem it solves.",
      "points": [
        "Key feature or highlight one.",
        "Key feature or highlight two.",
        "Key feature or highlight three."
      ],
      "link": "https://my-new-project.example.com",
      "techStack": ["React.js", "Node.js", "PostgreSql"]
    }
    ```
  </Step>
  <Step title="Add the project image">
    Place the project screenshot or cover image in `public/assets/` and use `/assets/filename.jpg` as the `image` value in the JSON. The path is relative to the `public/` directory.
  </Step>
  <Step title="Save the file">
    Save `Project.json`. The new `ProjectCard` appears automatically in the Projects section on the next page load.
  </Step>
</Steps>

<Note>
  Project images are served from `/public/assets/`. Reference them as `/assets/filename.jpg` in the JSON — do not include the `public` prefix in the path.
</Note>
