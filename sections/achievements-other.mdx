---

The Achievements section showcases certifications, course completions, and competitive programming milestones. The Other section highlights personal side projects that fall outside the main portfolio projects — things like kernel development, ROM porting, and bot maintenance. Both sections load data from their respective JSON files via `useSectionData`, map over the entries, and render each one as a `Card` component in a two-column grid.

## AchievementItem type

Achievements use the `AchievementItem` interface from `src/app/types/Section.ts`. Unlike `CommonItem`, the `link` field is required:

```typescript src/app/types/Section.ts
export interface AchievementItem {
  title: string;
  subtitle: string;
  duration: string;
  detail: string;
  link: string;
}
```

Other projects use the `CommonItem` interface (shared with Experience and Education), where `link` is optional:

```typescript src/app/types/Section.ts
export interface CommonItem {
  title: string;
  subtitle: string;
  duration: string;
  detail: React.ReactNode;
  className?: string;
  link?: string;
  linkIcon?: IconType;
}
```

## Adding an achievement

Open `src/app/data/Achievement.json` and append a new object. The `link` field is required by `AchievementItem` — provide the URL of the certificate, course page, or profile:

```json
{
  "title": "AWS Cloud Practitioner",
  "subtitle": "Amazon Web Services",
  "duration": "2025",
  "detail": "Passed the AWS Certified Cloud Practitioner exam, demonstrating foundational knowledge of AWS cloud concepts, services, security, and pricing.",
  "link": "https://www.credly.com/badges/your-badge-id"
}
```

Save the file. The new card appears in the Achievements section automatically.

<Info>
  Achievements with a `link` field render a "Visit" button on the card that links directly to the certificate or profile. Because `link` is required by the `AchievementItem` interface, every achievement entry must include a URL.
</Info>

## Adding an "Other" project

Open `src/app/data/Other.json` and append a new object. The `link` field is optional for this section — include it only if you want to link to a repository, release page, or external resource:

```json
{
  "title": "CLI Task Manager",
  "subtitle": "Personal Project",
  "duration": "2024",
  "detail": "A command-line task manager written in Python with support for priorities, deadlines, and SQLite-backed persistence.",
  "link": "https://github.com/davinash97/cli-task-manager"
}
```

Save the file. The new card appears in the Other section automatically.
