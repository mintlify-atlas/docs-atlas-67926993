Avinash's Portfolio is a single-page application built by Avinash to present his skills, projects, work experience, education, and more in one place. It is built on Next.js 16 and React 19, written entirely in TypeScript, styled with TailwindCSS v4, and animated with Framer Motion. The site is deployed to Netlify with a custom domain and a server-side contact form powered by Netlify Functions and nodemailer.

| nodemailer | 7 | Email delivery from the contact form |

## Design principles

The codebase follows several deliberate conventions to keep it maintainable as it grows.

**DRY architecture.** Logic and markup are not duplicated. Shared behaviour is extracted into reusable components under `src/app/components/` so individual section pages stay focused.

**Data separation.** Content (projects, skills, experience entries, etc.) lives in JSON files under `src/app/data/` rather than being hardcoded inside components. Updating portfolio content means editing a data file, not touching component logic.

**Web Worker off-thread loading.** Data loading is delegated to a Web Worker (`src/app/worker/LoadData.ts`) so the main thread is not blocked while section data is fetched and parsed.

**Reusable components.** Each section consumes shared component primitives, avoiding one-off implementations that are hard to maintain.

**Naming conventions.** Functions use `camelCase`, constants use `SCREAMING_CASE`, and regular variables use normal case. This makes it easy to tell at a glance what kind of identifier you are looking at.

**TypeScript strict types.** All section data shapes are defined in `src/app/types/Section.ts` using TypeScript interfaces (`CommonItem`, `ProjectItem`, `SkillItem`, `AchievementItem`, `ContactItem`) and a discriminated `SectionDataMap` type, making data mismatches a compile-time error rather than a runtime surprise.

## Portfolio sections

The `Home` component in `src/app/page.tsx` renders nine sections in order:

| Section | Description |
|---|---|
| **Hero** | The opening banner — Avinash's name, title, and primary call-to-action links. |
| **About** | A short biographical introduction with personal background. |
| **Skill** | A categorised list of technical skills grouped into sets. |
| **Project** | Featured projects with images, descriptions, tech stacks, and links. |
| **Experience** | Work history entries with title, company, duration, and detail. |
| **Education** | Academic background with institution, degree, and duration. |
| **Achievement** | Certifications, awards, or notable accomplishments with verifiable links. |
| **Other** | Miscellaneous items such as open-source contributions or side activities. |
| **Contact** | A contact form and social links for getting in touch. |
