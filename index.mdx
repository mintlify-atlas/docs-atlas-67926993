Avinash's portfolio is a single-page web application that showcases skills, projects, work experience, education, and achievements. Built with Next.js 16, TypeScript, TailwindCSS v4, and Framer Motion, it features smooth animations, auto dark mode, a Web Worker-powered data layer, and a rate-limited contact form backed by a Netlify serverless function.

## Quick overview

<Steps>
  <Step title="Clone the repository">
    Get the source code from GitHub and install dependencies with Node.js.
  </Step>
  <Step title="Run locally">
    Start the Next.js dev server with Turbopack for instant hot-reload.
  </Step>
  <Step title="Customize your data">
    Edit the JSON files in `src/app/data/` to add your own skills, projects, and experience.
  </Step>
  <Step title="Deploy to Netlify">
    Push to GitHub — Netlify automatically builds and deploys with the `@netlify/plugin-nextjs` adapter.
  </Step>
</Steps>
